# Other Services

!!! overview "On this Page"
    - What eResearch Otago offers beyond the Aoraki cluster
    - Hosted applications, cloud native platforms and training
    - Who to ask when you are not sure what you need

Not every research computing problem is a batch job. Alongside the
[Aoraki cluster](../getting_started/overview.md) we run and support a number of other services —
some of them hosted applications you simply log in to, some of them platforms we help you
build on.

Most are available to any University of Otago researcher. Where a service needs to be set up
for you first, the page says so.

## Hosted Applications

Applications we run for you, reached through your browser.

Table: Applications hosted by eResearch Otago

| Service | What it is |
| :-- | :-- |
| [CryoSPARC](hosted/cryosparc.md) | Cryo-EM single particle analysis, on dedicated hardware and the cluster's GPU nodes |
| [Database hosting](hosted/databases.md) | PostgreSQL and MariaDB instances for research data |
| [Large Language Models and GenAI](hosted/llm.md) | An OpenAI-compatible gateway to LLMs hosted on campus |
| [SAS Studio](hosted/sas.md) | The SAS Studio IDE, with access to your HCS shares |
| [ShinyProxy](hosted/shinyproxy.md) | Hosting for R Shiny apps and other containerised applications |
| [Speech-to-Text and Transcription](hosted/stt.md) | Offline transcription, subtitling and translation of audio and video |
| [Translation](hosted/translate.md) | An on-campus machine translation interface and API |
